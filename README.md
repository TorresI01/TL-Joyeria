# TL Joyería

Sitio web estático para catálogo de joyería con carrito, filtro por categorías y pedido por WhatsApp.

## Preview local

Abre el archivo `index.html` directamente en el navegador o sirve la carpeta con un servidor local.

Ejemplo:

```bash
python -m http.server 8000
```

Luego visita: http://localhost:8000

## Publicación en GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube estos archivos: `index.html`, `styles.css`, `script.js`.
3. En el repositorio, ve a `Settings > Pages`.
4. Selecciona `Deploy from a branch`.
5. Rama: `main`.
6. Folder: `/root`.
7. Guarda.

La URL será algo como:

```text
https://tu-usuario.github.io/tu-repositorio/
```
